# App Store Optimization

## Scope
Maximizing app discoverability and conversion in app stores: metadata, screenshots, ratings, reviews, and marketing.

## Core principles
- App Store algorithms (both Apple and Google) rank by relevance (keyword match), popularity (downloads, ratings), and engagement (DAU, retention) — optimizing metadata improves discoverability, but quality product matters most.
- Keywords are matched against app name, subtitle, and keyword field (iOS); Android uses description — choose 1–3 high-volume, low-competition keywords (research with App Annie, Sensor Tower).
- Screenshots are the first impression; the first 2–3 should show value without text (quick scan); captions help, but clarity matters more than design.
- Ratings and reviews heavily influence conversion: aim for 4.5+ stars (apps below 4.0 see <5% conversion); promptly respond to negative reviews and iterate on feedback.
- A/B testing app icons, screenshots, and descriptions via App Store Connect (iOS) or Google Play Console — small changes (icon color, tagline) can improve conversion by 10–20%.

## Apex practices
- Localize metadata for top markets; translated app name and keywords in local language improve discovery.
- Use the first screenshot to show the core value prop (not the logo or onboarding); measure conversion per screenshot variant.
- Monitor trending keywords with App Annie, Sensor Tower; seasonal trends (fitness apps in January) can drive installs with timed ASO.
- Incentivize five-star reviews via in-app prompts post-key-action (after completing a task, not on launch).

## Pitfalls
- Keyword stuffing (cramming unrelated keywords) reduces relevance and gets apps flagged; focus on a few high-intent keywords.
- Ignoring negative reviews; 1-star reviews cite problems (crashes, bugs) — fixing them is more ROI than fighting reviews.
- Assuming screenshots should showcase design; they should showcase functionality — prospective users need to understand what the app does.

## Tools & references
App Annie (data.ai), Sensor Tower, Mobile Action for keyword research; App Store Connect, Google Play Console analytics; "Traction" (Weinberg & Mares) for growth strategies.
