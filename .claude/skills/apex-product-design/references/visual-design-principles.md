# Visual Design Principles

## Scope
Fundamentals of visual composition: hierarchy, alignment, balance, contrast, and white space for clarity and impact.

## Core principles
- Visual hierarchy guides the eye to important elements; size, color, and position create emphasis — without hierarchy, all elements compete and nothing stands out.
- Alignment creates visual order and reduces cognitive load; random positioning confuses; grid-based layouts (8px, 16px) align elements and feel coherent.
- Contrast (size, color, weight) separates elements and creates visual interest; too much contrast overwhelms, too little makes things invisible.
- White space (negative space) is not empty; it separates elements, reduces clutter, and directs attention — generous white space reads as premium/calm, cramped reads as chaotic.
- Balance can be symmetrical (formal, stable) or asymmetrical (dynamic, interesting) — both work, but mixed balance (symmetry on one axis, asymmetry on another) looks unintentional.

## Apex practices
- Use typographic hierarchy (size, weight, color) to create readable hierarchy without excessive visual complexity.
- Build on grids (8px or 16px multiples) for consistent spacing and alignment; grids make small adjustments invisible, breaking them visible.
- Test contrast ratios (≥4.5:1 for text, ≥3:1 for UI elements) to ensure accessibility; use contrast checkers to validate.
- Embrace white space; margins and padding are often the quickest way to improve cluttered designs.

## Pitfalls
- Unclear hierarchy: too many "important" elements means none are truly important; prioritize ruthlessly.
- Broken alignment: a single element off-grid feels wrong; check all elements align with the grid.
- Insufficient contrast between text and background; low contrast is hard to read and fails accessibility standards.

## Tools & references
Layout grids, design systems, WCAG contrast guidelines, "Thinking with Type" (Lupton), "The Design of Everyday Things" (Norman); Figma grids and auto-layout.
