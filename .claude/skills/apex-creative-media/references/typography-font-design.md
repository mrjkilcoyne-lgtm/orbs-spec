# Typography & Font Design

## Scope
Designing and selecting typefaces: form, readability, hierarchy, and creating or modifying fonts to communicate and guide reading.

## Core principles
- Typeface choice communicates before a single word is read: serif feels formal, sans-serif feels modern, script feels personal; font personality must match content intent.
- Readability (letterforms are distinct and clear) vs. legibility (text is easy to read at size and distance); they're different: a typeface can be readable but illegible at 8pt, or vice versa.
- Hierarchy is scale, weight, color, and spacing: a headline is larger and heavier, body text is regular weight, captions are smaller and lighter; hierarchy guides eye to importance.
- Kerning (space between letter pairs) is optical, not mathematical: AA might need less space than AV because shapes are different; kerning tables and manual adjustment separate professional type from amateur.
- A font is 26 letters (or thousands for complex scripts) with consistent color and structure; designing a typeface requires understanding letterforms, proportions, and how spacing works across all combinations.

## Apex practices
- Choose body text first (for readability at the intended size), then pair a contrasting display face for headlines (different x-height, weight, or style).
- Use font weights (light, regular, bold) and styles (italic) to create hierarchy within a typeface instead of switching families; it's more cohesive.
- Set leading (line-height) to 1.3–1.5x the font size for body text; it improves readability and prevents cramping.
- Test fonts at actual size and on actual medium (screen, print) before committing; small samples can mislead.

## Pitfalls
- Using more than 3 typefaces (headline, body, accent) in a design; it looks scattered.
- Ignoring font licensing (web fonts, embedding rights, commercial use); using a font without permission is copyright violation.
- Setting tiny type with tight leading and expecting readability; better to use fewer words in larger type.

## Tools & references
