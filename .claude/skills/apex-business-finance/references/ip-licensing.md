# IP Licensing

## Scope
Intellectual property creation, ownership, and licensing: patent strategy, open-source licensing, trademark basics, and ensuring IP is assigned to the company.

## Core principles
- Ownership follows creation unless explicitly assigned; if an employee writes code without an assignment agreement, they may own the IP, and the company is licensing it (or has nothing).
- Patent utility (does it protect the business?) is more important than patent quantity; a 20-claim patent that covers a key algorithm is worth more than 100 thin patents.
- Open-source licensing (GPL, MIT, Apache) comes with obligations; GPL requires derived works to be open-sourced, while MIT allows proprietary derivatives — choose the license that matches your business model.
- Trade secrets (undocumented algorithms, customer lists) require secrecy agreements and controlled access; once disclosed, trade secret protection is lost forever.
- Trademark registration is jurisdiction-specific; trademark.com does not grant protection outside the US; international protection requires filing in each country.

## Apex practices
- Have all employees and contractors sign IP assignment agreements on day one; assign all prior IP created before employment (even as a founder, this clarifies ownership).
- File for patents in the market where you want protection (US, EU, China); patent attorneys typically file in all three simultaneously (PCT — Patent Cooperation Treaty).
- Document trade secrets in writing (mark confidential) and control access; once a customer sees your pricing algorithm, it's potentially exposed and loses protection.
- Choose open-source license strategically based on distribution model: SaaS (AGPL) triggers copyleft obligations if code is run on servers; on-premise (GPL) triggers if code is distributed; libraries (MIT) allow maximum flexibility.

## Pitfalls
- Assuming prior employment IP is owned by the company without an assignment agreement; in some jurisdictions (CA), only IP "related to the company's business" is automatically assigned.
- Neglecting trademark registration and losing common law rights; register trademarks before scaling internationally.
- Over-patenting and starving the budget; 20 patents nobody uses cost more than 3 patents that are core to the business.

## Tools & references
USPTO (patent, trademark), WIPO (international), Github's open-source license chooser, SPDX license list, Fenwick & West IP agreements, "The Lean Startup" on MVP intellectual property strategy.
