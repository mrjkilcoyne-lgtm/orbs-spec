# Memory Techniques

## Scope
Mnemonic systems for deliberate memorization: method of loci, pegs, encoding systems for numbers and names, and when mnemonics beat rote.

## Core principles
- Memory athletes have ordinary brains using extraordinary encoding (Maguire's fMRI studies): they convert abstract data into vivid spatial-visual scenes, exploiting the brain's evolved strengths — places, images, stories — instead of its weakness for arbitrary symbols.
- The method of loci (memory palace) works because spatial memory is nearly effortless: items imaged at loci along a known route inherit the route's durability; it has been the core technique from Simonides (~500 BC) to every modern memory championship.
- Elaboration strength scales with distinctiveness: bizarre, exaggerated, multisensory, emotionally-charged images encode better than plain ones (the von Restorff effect) — the embarrassing image you'd never say aloud is the one that sticks.
- Mnemonics are for arbitrary mappings, not understanding: they excel at names, numbers, vocabulary, lists, and anatomical terms; they cannot substitute for comprehension of systems — encode the label mnemonically, learn the mechanism conceptually.
- Encoding is only half; retrieval practice consolidates: a memory palace reviewed on a spaced schedule lasts years; unreviewed, even vivid images fade — mnemonics and spaced repetition are complements, not competitors.

## Apex practices
- Build a portfolio of palaces from over-learned routes (childhood home, commute, campus) and reuse them for different content after a fallow period; number loci in fives for random access.
- For numbers, learn the Major system (digits→consonant sounds→words: 3.14159 → "meter, tail, pie...") or, for serious volume, a PAO (person-action-object) system encoding 6 digits per locus.
- For names: hear it, say it back, transform it into an image (Baker→a baker's hat), and bind the image to the person's most distinctive facial feature — the "Baker/baker paradox" shows meaning is what makes names stick.
- Chain new vocabulary with the keyword method (foreign word → similar-sounding known word → image linking to meaning), one of the best-evidenced mnemonic techniques in the literature.

## Pitfalls
- Using mnemonics for material that needs understanding — a medical student who can list the cranial nerves via mnemonic but not localize a lesion has memorized the index, not the book.
- Weak, tasteful images: the technique fails politely when images are literal and calm; vividness is the mechanism, not decoration.
- Palace interference: loading a second list into a palace before the first is retired or consolidated blends the two.
