# Retelling & Recasting

## Scope
Remix, adaptation, appropriation: carrying a work across media, eras, and contexts so it arrives transformed but recognizable.

## Core principles
- Every retelling picks an invariant: adaptation means choosing what survives the crossing — plot, mood, structure, or argument — and rebuilding everything else natively in the target medium. Kurosawa keeps Macbeth's ambition-spiral and rebuilds every scene as Noh; a port that keeps the surface and loses the invariant is a "faithful" failure.
- Recasting reveals the original: putting the Odyssey in Dublin (Joyce) or Depression Mississippi (O Brother) X-rays the structure — you learn what the source is actually made of only when you rebuild it elsewhere. Same law as porting code: the rewrite exposes the implicit spec.
- Appropriation must add a position (Duchamp's moustache, Sherrie Levine's rephotographs): quotation without transformation is theft-flavored decoration; the recast has to argue with, honor, or reframe its source — fair use law (transformativeness) tracks the same intuition.
- The audience's prior knowledge is material: retellings run on the gap between what the audience expects (the known story) and what you deliver — subversion, delay, and fulfillment are the levers. No shared prior, no gap, no charge.
- Versions form a conversation, not a lineage of decay: West Side Story doesn't degrade Romeo and Juliet; strong retellings send readers back to the source. Design systems live the same way — each product's recast of the pattern feeds the canon.

## Apex practices
- Write the invariant sentence before recasting anything: "this is a story/layout/system about X, and X survives the move" — every adaptation decision checks against it.
- Translate idioms, not words: find the target medium's native equivalent for each source device (voiceover → caption, brushstroke → dither pattern, chapter → scroll section) rather than embedding the source device raw.
- Recast as a critique tool: redo an existing design in a deliberately foreign style (your dashboard as a 1960s Swiss poster, as a Game Boy screen) — the exercise exposes which decisions were essential and which were habit.
- Track provenance visibly: name your sources in the work or its colophon; it converts borrowing into lineage and keeps you honest about what you added.

## Pitfalls
- Surface-porting: moving the look while abandoning the logic (the movie-of-the-game problem; the Bootstrap-theme-of-the-brand problem).
- Reference density as substance: allusion-stuffed work that only quotes and never speaks.
- Ignoring rights and credit — appropriation art's court history (Rogers v. Koons, Cariou v. Prince) is required reading before commercial recasting.
