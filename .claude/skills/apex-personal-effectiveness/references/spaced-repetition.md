# Spaced Repetition

## Scope
Long-term retention via expanding review intervals: card design, scheduling algorithms, and sustainable deck practice.

## Core principles
- The spacing effect (Ebbinghaus, 1885) is among the most replicated findings in psychology: reviews spaced over time produce dramatically better retention than the same number massed together.
- Reviews should land near the edge of forgetting: recall that requires effort strengthens memory more than easy recall (retrieval strength vs. storage strength, Bjork's two-component model).
- Card design dominates algorithm choice: the minimum information principle (Wozniak's 20 rules) — one atomic fact per card, unambiguous prompts — matters more than SM-2 vs. FSRS.
- A spaced-repetition system is a lifetime contract with your future self: adding a card commits you to ~1–2 minutes of cumulative review over a decade (Branwen's estimate), so curate ruthlessly.
- Recognition-format cards create false confidence; cards must force production (cloze deletion, "what command does X") or the ease ratings lie.

## Apex practices
- Write cards from both directions where meaningful (term→definition and definition→term are different memories) and add context cues to prevent interference between similar cards.
- Prefer FSRS (in Anki since 23.10) over legacy SM-2 — it fits a memory model per user and cuts review load 20–30% at equal retention; set desired retention explicitly (0.85–0.90 for most material).
- Cap new cards/day (10–20) and never skip review days entirely — the backlog spiral is the number-one cause of abandonment.
- Use incremental card creation from real encounters: card a fact when you look it up the second time; decks built from lived need beat imported shared decks.

## Pitfalls
- Carding material you don't understand yet — spaced repetition maintains understanding, it doesn't create it (understand first, then memorize).
- Giant "orphan" cards with three facts each: they fail repeatedly, get suspended, and poison motivation.
- Treating leeches (cards failed 8+ times) as a willpower problem instead of a card-design problem — rewrite or delete them.
